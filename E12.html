ATR و اندازه‌گیری نوسان

در انتظار بررسی وحید

هدف: مشخص شود کدام ATR، در کدام تایم و با چه اطلاعاتی مبنای اندازه‌گیری است.

قواعد جاری پس از پاسخ‌های ۴ نوامبر

پاسخ‌های نسخهٔ قبلی با هش و منابع تطبیق داده شدند؛ اصلاح‌ها اعمال شده و نسخهٔ جدید نیازمند مرور است.

  • فرمول مرجع با ۲۱ حفظ شده و ATR کافی‌نبودن هشدار دارد.
  • پایش زنده از snapshot مشاهده‌شده استفاده می‌کند؛ بازپخش تاریخی از سقف/کف آینده استفاده نمی‌کند.

۱. شماتیک قبلی منبع؛ برای مقایسه

تمام اعداد و نمودارهای این پرونده شماتیک و مصنوعی‌اند. هیچ‌کدام شاهد بازار واقعی، خروجی بک‌تست یا تأیید وحید نیستند.

۲. شواهد کد و منبع؛ پروفایل مرجع قبلی

  1. مسیر غیرماهانه TrexATR از دوره‌های ۵، ۱۰، ۲۱، ۶۶، ۱۳۲ و ۲۶۴ با وزن‌های ۱، ۱، ۲، ۳، ۵ و ۸ و تقسیم بر ۲۰ استفاده می‌کند.
  2. مسیر ماهانه مستقیماً iATR(MN1,55,shift) را برمی‌گرداند؛ از همان مسیر گردکردن و guard بعدی عبور نمی‌کند.
  3. PivotTrexATR فرمول وزنی مشابه دارد، ولی guard صریح مجموع غیرمثبت TrexATR را ندارد.
  4. ATR لگ = طول لگ / ۲٫۴ است و از همان داده شش ATR به دست نمی‌آید. الگوریتم داخلی iATR و warm-up هنوز با اجرای MT4 تطبیق داده نشده است.

دامنه کد پژوهشی این نسخه

TR و ATR از OHLC، SMA/Wilder، warm-up صریح، ترکیب شش دوره و مسیر ماهانه در Python اجرا می‌شوند؛ MT4 وابستگی اجرا نیست و ادعای برابری دقیق نداریم. پاسخ ۴ نوامبر: فرمول مرجع ۲۱ حفظ و هشدار دادهٔ ناکافی اضافه شد.

عبور آزمون‌های مصنوعی به معنی تطابق اجرای MT4، تأیید وحید یا تکمیل Epic نیست.

ATR-001 — TrexATR

Recources/pivot 3.txt · خطوط 572–584

For non-monthly timeframes: (ATR5 + ATR10 + 2*ATR21 + 3*ATR66 + 5*ATR132 + 8*ATR264)/20; nonpositive sum returns zero, otherwise NormalizeDouble(sum,_Digits). Timeframe zero maps to _Period.

SHA-256: 96d69f6d4b9fb96f23eff3af3b5d278e5f685ad232bfea773c94c289afaef181

572: double TrexATR(string symbol, int timeframe, int shift) {
573:     if(timeframe == 0) timeframe = _Period;
574:     if(timeframe == PERIOD_MN1) return iATR(symbol, PERIOD_MN1, 55, shift);
575:     double atr5   = iATR(symbol, timeframe, 5, shift);
576:     double atr10  = iATR(symbol, timeframe, 10, shift);
577:     double atr21  = iATR(symbol, timeframe, 21, shift);
578:     double atr66  = iATR(symbol, timeframe, 66, shift);
579:     double atr132 = iATR(symbol, timeframe, 132, shift);
580:     double atr264 = iATR(symbol, timeframe, 264, shift);
581:     double sum = (atr5 * 1.0 + atr10 * 1.0 + atr21 * 2.0 + atr66 * 3.0 + atr132 * 5.0 + atr264 * 8.0) / 20.0;
582:     if(sum <= 0.0) return 0.0;
583:     return NormalizeDouble(sum, _Digits);
584: }
