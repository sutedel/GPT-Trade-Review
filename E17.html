در انتظار بررسی وحید

هدف: تبدیل OHLC به ویژگی‌های قابل اندازه‌گیری و سپس برچسب نسخه‌دار؛ برچسب کندل به‌تنهایی سیگنال معامله نیست.

۱. مثال دیداری برای بررسی

تمام اعداد و نمودارهای این پرونده شماتیک و مصنوعی‌اند. هیچ‌کدام شاهد بازار واقعی، خروجی بک‌تست یا تأیید وحید نیستند.

۲. برداشت مستند فعلی

  1. هندسه مثال: O=100، H=112، L=98، C=108؛ دامنه ۱۴، بدنه ۸، سایه بالا ۴ و سایه پایین ۲ واحد قیمت است. این محاسبه هندسی است.
  2. در GetCandleType ابتدا ATR نامعتبر رد می‌شود. برای C>=O سایه بالا و برای C<O سایه پایین سنجیده می‌شود؛ سایه بیش از ۵۰٪ ATR بر همه برچسب‌ها تقدم دارد.
  3. پس از شرط سایه: دامنه کمتر از ۸۰٪ → SP؛ تا ۱۲۰٪ → S؛ تا ۲۴۰٪ → L؛ بیشتر → SPK. شروط برابری دقیقاً مطابق کدند.
  4. متن آموزشی مرز ۲۵۰٪ و شرط ۸۰٪ بدنه دارد؛ این profile با کد وحید یکی نیست. دوجی در GetCandleType سمت صعودی دارد، ولی در شروط رنگی پیوت پذیرفته نمی‌شود.

دامنه کد پژوهشی این نسخه

طبقه‌بندی کندل مستقیماً به ATR محاسبه‌شده از OHLC وصل است؛ هر دو سایه، LSH و مرزهای مرجع رعایت می‌شوند. مستر و کندل ترکیبی هنوز تعریف اجرایی ندارند.

عبور آزمون‌های مصنوعی به معنی تطابق اجرای MT4، تأیید وحید یا تکمیل Epic نیست.

CND-001 — GetCandleType

Recources/pivot 3.txt · خطوط 3823–3834

ATR<=0 gives empty label. RangePct=(H-L)/ATR*100. Bullish includes C>=O. Directional shadow is H-max(O,C) for bullish, min(O,C)-L otherwise. Priority: shadowPct>50 => LSH; else rangePct<80 => SP; <=120 => S; <=240 => L; otherwise SPK.

SHA-256: 96d69f6d4b9fb96f23eff3af3b5d278e5f685ad232bfea773c94c289afaef181

3823: string GetCandleType(double open, double high, double low, double close, double atrVal) {
3824:     if(atrVal <= 0) return "";
3825:     double fL  = high - low;
3826:     double fLP = (fL / atrVal) * 100.0;
3827:     bool   isB = (close >= open);
3828:     double bTop = MathMax(open, close);
3829:     double bBot = MathMin(open, close);
3830:     double alSP = (isB ? (high - bTop) : (bBot - low)) / atrVal * 100.0;
3831:     // همان منطق دقیق CTF_CreateCandle:
3832:     string lTxt = (alSP > 50.0) ? "LSH" : (fLP < 80.0) ? "SP" : (fLP <= 120.0) ? "S" : (fLP <= 240.0) ? "L" : "SPK";
3833:     return lTxt;
3834: }
